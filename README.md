# Disaster Recovery & Backup Automation

This repository contains automation scripts used for enterprise backup validation, LVM snapshot management, restore testing, and Disaster Recovery (DR) operations.

These tools help ensure:
- Backup integrity  
- DR readiness  
- Restore capability  
- Compliance with enterprise standards

## 🚀 Scripts Overview

### 🔹 **dr-verify.sh**
Validate DR readiness by checking critical file systems, backups, and required services.

### 🔹 **rsync-backup.sh**
Automate backups using rsync with logging and error reporting.

### 🔹 **lvm-snapshot-create.sh**
Create LVM snapshots for consistent backups.

### 🔹 **restore-test.sh**
Perform a test restore to validate backup integrity.
